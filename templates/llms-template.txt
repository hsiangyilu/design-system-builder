## Core Rule: Closed Set

You MUST only use the named tokens listed below when generating any UI.
- NEVER invent hex colors, even plausible-looking ones.
- NEVER use Tailwind arbitrary values: `bg-[#...]`, `text-[13px]`, `w-[...]`, `p-[...]` are all forbidden.
- NEVER hard-code px font sizes. Use the typography tokens.
- If no token fits, STOP and ask the user. Do not approximate.

## Typography Tokens

display/hero   → text-display-hero    → h1, one per page maximum
display/xl     → text-display-xl      → h2, section heroes
heading/lg     → text-heading-lg      → h3, page titles
heading/md     → text-heading-md      → h4, block titles
heading/sm     → text-heading-sm      → h5, card titles
label/lg       → text-label-lg        → h6, nav items, buttons
body/md        → text-body-md         → p, all body copy (16px base)
body/sm        → text-body-sm         → small, helper text
caption        → text-caption         → meta, timestamps (minimum size)

## Do

- DO use `font-display` only for display/* and heading/* tokens.
- DO use `font-body` for everything from label/lg down.
- DO use semantic color tokens; primitive scale values (e.g. `blue-400`) are for token definition only, never in components.
- DO run `node scripts/audit-tokens.mjs` after generating code and fix every reported violation before presenting the result.

## Don't

- DON'T use display font for body copy or anything below label/lg.
- DON'T place text.secondary on background.overlay (contrast fails).
- DON'T use feedback colors for decoration; they carry state meaning only.
